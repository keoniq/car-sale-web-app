# Car Sale Web App

Live App: https://car-sale-web-app-final.onrender.com/

## Description

This Streamlit web application allows users to explore used car listings, filter by type and condition, and view visualizations like a scatter plot and histogram to help understand car price trends.

## How to Run Locally

Follow these steps to run the app on your local machine:

### 1. Clone the repository

```bash
git clone https://github.com/keoniq/car-sale-web-app-final.git
cd car-sale-web-app-final
```

### 2. Create a virtual environment (optional but recommended)

```bash
python -m venv venv
source venv/bin/activate     # On macOS/Linux
venv\Scripts\activate        # On Windows
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the app

```bash
streamlit run app.py
```

Then open `http://localhost:8501` in your web browser.
